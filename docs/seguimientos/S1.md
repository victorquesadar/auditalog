## 4. Decisiones técnicas tomadas

| Decisión | Alternativa descartada | Motivo |
|---|---|---|
| Python + FastAPI | PHP | Mejor soporte asíncrono y drivers maduros para los 3 motores |
| MongoDB Atlas (no local) | Mongo local en el VPS | El profesor puede verificar desde fuera; sube la nota de reproducibilidad |
| Prefijo Redis `grupo4:auditalog:` | Prefijo solo `grupo4:` | Deja espacio a futuros proyectos del grupo en el mismo Redis |
| `raw` embebido en `events`, `event_ids` por referencia en `alerts` | Todo embebido | Alertas con muchos eventos harían crecer documentos sin necesidad |
| SQLite solo para el paquete de evidencia, no almacén principal | SQLite como almacén | Es la justificación del motor según la propuesta (archivo portable) |
