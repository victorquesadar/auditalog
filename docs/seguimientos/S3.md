## 2. Mediciones (resumen)

Ver detalle completo en [`docs/mediciones/mediciones_s3.md`](../mediciones/mediciones_s3.md).

| Operación | Baseline | Optimizado | Mejora |
|---|---|---|---|
| **Mongo** inserción masiva 5000 docs | mediana sin índice | mediana con índice | esperado: no significativo (el índice ayuda a SELECT, no a INSERT) |
| **Dashboard** aggregation | ~10-50 ms sin caché | ~0.1-1 ms con caché Redis | **10-100× speedup** |
| **SQLite** query `WHERE ip = ? AND ts >= ?` | ~0.9 ms sin índice (SCAN) | ~0.6 ms con índice (SEARCH USING INDEX) | **~30% más rápido** |

**EXPLAIN QUERY PLAN** confirma el cambio de `SCAN events` a `SEARCH events USING INDEX idx_ip_ts`.

## 3. Qué quedó pendiente

- **Despliegue en Virtualmin del curso** → se queda para S4.
- **Múltiples workers paralelos**: implementable con el consumer group ya en uso, pero no lo priorizamos vs. las mediciones. Queda documentado en decisiones (D-08).
- **Autenticación de usuarios en el dashboard** → una cuenta admin para S4, sigue sin login.
- **Procesamiento asíncrono de archivos grandes** (>50 MB) → job queue en S4 (ver D-13).

## 4. Bloqueos

Ninguno. Las reglas HTTP se probaron con tráfico sintético porque el VPS del grupo no tiene access.log de un sitio público — para S4 el profesor podría pasarnos un log real anonimizado.

## 8. Comandos para la demo (viernes 30-oct)

```bash
# 1. Verificar los 3 motores
python scripts/hello_all.py

# 2. Correr los tests
python -m pytest tests/ -v        # 50/50 ✓

# 3. Reproducir las mediciones (3 corridas × 3 operaciones)
python scripts/benchmarks.py --all --n 5000 --runs 3

# 4. Levantar el dashboard
uvicorn src.api.main:app --reload
# → http://localhost:8000/

# 5. Subir un archivo de log (nueva función)
# en el navegador: /subir → elegir archivo → procesar

# 6. Simular ataques HTTP para disparar las 6 reglas nuevas
curl -X POST http://localhost:8000/api/ingest \
  -H "Content-Type: application/json" \
  -d '{"source":"access.log","action":"http_request","ip":"203.0.113.5","severity":"warn","detail":{"path":"/products?id=1 UNION SELECT","method":"GET","status":200}}'
```
