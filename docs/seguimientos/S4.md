## 8. Comandos para la demo (viernes 06-nov)

```bash
# 1. Verificar los 3 motores
python scripts/hello_all.py

# 2. Tests
python -m pytest tests/ -v        # 102/102 ✓

# 3. (Opcional) Descargar GeoIP para cobertura completa
python scripts/download_geoip.py   # DB-IP Lite gratis, sin registro

# 4. Levantar el dashboard
uvicorn src.api.main:app --reload
# → http://localhost:8000/

# 5. Activar login (opcional, para probar como en Virtualmin)
# En .env:
#   AUTH_USER=admin
#   AUTH_PASS=s3cret
# Reiniciar uvicorn

# - Subir un .zip con varios logs (/subir)
# - Ver el origen (/geo) con países y ASN
# - Click en "🔍 Descubrir IPs desconocidas"
```
