Exportar paquete de evidencia

Genera un archivo .db SQLite autocontenido con todos los eventos y alertas del período que elijas. El auditor lo abre con DB Browser for SQLite, DBeaver o cualquier cliente SQL — no necesita acceso al servidor ni a MongoDB.

Período

Qué incluye el paquete

  • Tabla events — todos los eventos del período con sus índices
  • Tabla alerts — alertas disparadas en el período
  • Tabla package_meta — fecha de generación, período, cantidades y SHA-256 de integridad

Vistas pregeneradas para el auditor

  • v_fuerza_bruta — IPs con ≥5 fallos de login
  • v_cambios_config — modificaciones a archivos de configuración
  • v_accesos_offhours — logins entre 22:00 y 06:00
  • v_resumen_por_dia — eventos/críticos/warnings por fecha

El archivo tiene PRAGMA journal_mode = WAL activado para lectura concurrente.
