Subir archivo de log

Subí un archivo de log del servidor que querés auditar. El sistema parsea cada línea con el parser correspondiente, mete los eventos en MongoDB y aplica las reglas de detección en tiempo real.

0 %

Qué hace esta subida

  1. 1. El archivo llega al servidor en el endpoint POST /api/upload.
  2. 2. Se parsea cada línea con el parser elegido (regex).
  3. 3. Los eventos válidos se insertan en Mongo en lotes de 500.
  4. 4. Las reglas de detección se aplican a cada evento y crean las alertas.
  5. 5. El resumen te dice cuántas líneas se leyeron, insertaron, descartaron, y cuántas alertas se dispararon.

En producción esto reemplazaría al colector auth_log_collector.py para archivos puntuales (p. ej. logs archivados). Para flujo continuo seguís con el colector corriendo como servicio.
